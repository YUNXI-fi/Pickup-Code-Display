变更说明

相对当前线上版本，除视觉与布局外，含 2 处需要后端配合的新增

统一的部分

  • 「取件」主操作统一为蓝色（原管理页是绿色，展示页是蓝色，同义不同色）
  • 四个状态色固定语义：amber 待发货 / blue 运输中 / emerald 待取件 / gray 已取件，Badge、色条、筛选胶囊全部复用
  • 全部 emoji 占位图标（📦）替换为 SVG 图标
  • 卡片圆角 rounded-xl → rounded-2xl，按钮/输入框统一 rounded-xl

展示页改动

  • 取件码字号提升（PC 44px / 移动 30px），大屏远距离可读；每 4 位数字插一个空格便于对着屏幕输码（只切分连续数字段，9-1-4408 这类带横杠的码保持原样）
  • 卡片单列 → PC 三列网格、移动单列分层
  • 两个分段控件由上下堆叠改为左右分置，并吸顶
  • 卡片左侧色条整体去掉：它在「按取件地址」视图里表示分组、在「按取件情况」视图里又表示状态，同一个元素两种语义容易误读；色条现在只保留在分组标题上
  • 已取件卡片降级：灰底 + 删除线 + 无阴影 + 对勾徽标

管理页改动

  • 散卡片 → 单个容器 + 分隔行，PC 端加表头实现列对齐
  • 纯图标按钮 → 图标 + 文字（刷新 / 账号管理 / 添加快递）
  • 筛选胶囊增加各状态数量，并删掉此前点了没反应的「待发货」死按钮（列表与筛选都不含待发货：无取件码，避免干扰）
  • 新增「编辑」入口：PC 表格行内，移动端左滑侧滑
  • 移动端「取件 / 未取」从底部操作行提到卡片上方，与取件码同行
  • 移动端「编辑 / 删除」收进左滑，卡片常显按钮从 2–3 个减到 1 个
  • 移动端悬浮按钮改圆形 FAB（纯加号）
  • 「拍照识别」文案统一改「上传截图」（实际调起的是文件/相册选择器）
  • 录入弹窗 PC 改双列表单；移动端改底部抽屉，编辑复用同一抽屉
  • 账号管理由三级跳转（列表 → 选平台 → 配置）压成单窗左右分栏，平台项显示账号备注
  • 补上账号管理的移动端：平台列表 + 扫码登录两个底部抽屉，平台行整行可点、带状态徽标
  • 扫码 UI 重做：接入方式改「扫码登录 / 粘贴 Cookie」二选一分段切换，二维码放大到 PC 168px、移动 180px，三个状态各有明确视觉反馈（待扫 / 已扫待确认 / 过期压暗并浮出刷新）

需要后端配合的改动（不只是样式）

  • 新增编辑接口：PATCH /api/packages/:id，可改取件码 / 快递公司 / 收件人 / 尾号 / 取件地址。现在 app/server/routes/packages.js 里只有 /pickup 和 /restore，改不了已录入内容。编辑后照现有模式 broadcast('update', row) 即可复用已有 SSE 事件，前端不用新增监听。
  • 账号备注需要落库：现在账号信息只存了 Cookie（taobao_cookie 等）。要显示备注得新增一个存储键，Cookie 与备注一起读写。
  • 移动端侧滑为纯前端交互：复用现有 DELETE /api/packages/:id，不需要接口改动。

本轮按你的意见已定稿的两处： ① PC 管理页保留「表头 + 行」的表格化列表，操作列加宽以容纳「编辑 / 取件 / 删除」； ② 账号管理保留左右分栏，平台项显示账号备注——后端拿不到淘宝/拼多多昵称，改为你自己给账号起名字，不额外调用平台接口，也就没有额外风控风险。
