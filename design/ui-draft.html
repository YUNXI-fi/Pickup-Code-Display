MOBILE UI · V2

移动端 UI 优化设计稿

覆盖展示页与管理页两块移动端界面，重点在视觉打磨、信息层级与操作路径。沿用现有主色 #2563eb 与 Tailwind 体系，本稿仅示意、未实现。

390 × 780 展示页 2 屏 管理页 2 屏

视觉打磨

统一圆角与间距；弱化装饰元素（分组色条、重复图标），把对比度留给取件码与主操作。

信息层级

取件码第一优先，其次收件人，最后才是地址与快递号；地址按分组标题出现，卡片内不重复。

操作路径

常用操作前置到卡片；工具栏收成一行；取件后提供 5 秒撤回，降低误触成本。
